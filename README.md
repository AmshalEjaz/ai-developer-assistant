# DevPilot — AI Developer Assistant

DevPilot is a personalized AI developer assistant with a React/Vite frontend and a FastAPI backend. It supports AI chat, code-focused responses, authenticated user accounts, conversation history, persistent user memories, and a small registry of developer tools.

## Project structure

- `frontend/` — React + Vite application
- `backend/` — FastAPI API, agent, authentication, database, memory, and tools
- `TODO.md` — project implementation checklist
- `SECURITY.md` — security limitations and deployment guidance

## Requirements

- Python 3.10 or newer
- Node.js LTS and npm
- A Groq API key

## Local setup

### 1. Backend

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Create a local `.env` in `backend/` (never commit it) and set the environment values required by your deployment, including `GROQ_API_KEY` and a strong, private JWT secret according to `backend/main.py` and `backend/auth.py`.

Start the API:

```powershell
uvicorn main:app --reload
```

### 2. Frontend

Open a second terminal:

```powershell
cd frontend
npm ci
npm run dev
```

Open the local URL printed by Vite. Keep `package.json` and `package-lock.json`; `node_modules/` is generated by `npm ci` and should not be included in source ZIPs.

## Conversation history and persistent memory

DevPilot stores conversations, messages, and explicitly saved user memories in its local SQLite database (`backend/devpilot.db`). When a user asks about a previous chat, or asks a question that matches older discussion topics, the backend searches only that logged-in user's saved conversations and adds a bounded set of relevant excerpts to the AI context. The active conversation is excluded from historical retrieval. If the requested detail is not present in retrieved history, DevPilot is instructed not to invent it.

The memory feature and historical chat search are separate: saved memories hold durable notes/preferences, while historical retrieval finds details from actual past messages.

Run backend regression tests from `backend/` with:

```powershell
python -m unittest -v test_security_tools.py test_history_retrieval.py
```

## Security note

Python code execution is disabled by default because AST filtering is not a security sandbox. Read `SECURITY.md` before changing this behavior or exposing DevPilot to other users. Do not enable unsandboxed execution on a public server.

## Status

This is an active development project. Passing syntax checks or frontend regression tests does not imply that all API flows, AI behavior, or deployment settings have been fully tested.
